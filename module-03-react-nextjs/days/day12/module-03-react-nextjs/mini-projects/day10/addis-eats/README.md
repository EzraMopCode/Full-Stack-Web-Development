# 🍽️ Addis Eats

🌍 **Live Demo:** [View Addis Eats on Vercel] (https://full-stack-web-development-gray.vercel.app/)

Welcome to **Addis Eats**! 👋

Addis Eats is a modern, responsive frontend web application built to simulate a real-world Ethiopian food delivery experience. I built this project with a heavy focus on clean UI/UX, ensuring that the app is incredibly intuitive and easy to navigate, even for first-time users.

Whether you are browsing on a desktop or ordering from a smartphone, the interface adapts dynamically to provide a seamless, native-app experience.

## ✨ Key Features

* 📱 **App-Like Mobile Experience:** Features a sticky bottom navigation bar and a Floating Action Button (FAB) for the cart, making mobile browsing feel like a native iOS or Android app.
* ⚡ **Lightning Fast State Management:** Powered by Zustand, the cart and "Favorites" system update instantly across the app without unnecessary re-renders or prop-drilling.
* 🔍 **Interactive Menu:** Browse dishes with live search functionality and category filtering (Traditional, Vegan, Fast Food, Drinks).
* ❤️ **Favorites System:** Users can easily "heart" dishes to save them to their personal profile for quick ordering later.
* 🇪🇹 **Localized Checkout:** A clean checkout flow featuring local Ethiopian payment methods like Telebirr, CBE Birr, alongside Cash on Delivery.
* 🎨 **Beautiful UI:** Styled entirely with Tailwind CSS, utilizing clean layouts, smooth hover transitions, and crisp Lucide React icons.

## 🛠️ Tech Stack

* **Core:** React (Vite)
* **Styling:** Tailwind CSS (v4)
* **State Management:** Zustand
* **Routing:** React Router DOM
* **Icons:** Lucide React
