# Bistro Menu App

A simple React application built using Vite to practice JSX structure, component composition, and dynamic rendering via props.

## Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org) installed.

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Running the App
Start the local development server:
```bash
npm run dev
```
